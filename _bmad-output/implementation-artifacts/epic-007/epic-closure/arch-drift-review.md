# E007 architecture drift review (l3io-arch Mode B)

Scope: epic E007 sprint-01 (S01-001..004), commits 91f8222, 2b3de85, c4059b6, f1cf076. The raw range also carries E006's tracing/api files; those are not judged here.
Note: the findings-table IDs are `AD-n` for the spec-align tooling; this report, the closure report and the backlog also call them `ED-n` (same number) to avoid confusion with the architecture decisions AD-1/AD-4.
Method: read of the named diffs and modules, import-linter config, ADR-0015/0016/0022/0023, spine AD-1/AD-4/AD-7/AD-17. Findings come from reading code; no tests were run.

## Verdict by question asked

| Question | Result |
|---|---|
| Layering: core must not import adapters | Clean. `core/relocation.py` imports `core.restore`, `domain.*`, stdlib (`itertools`, `unicodedata`, `types`, none on the AD-1 forbidden list). `core/config_location.py` imports `domain.*` only. `adapters/preflight.py` and `adapters/wpcli.py` import `core/` (inward, allowed). `cli/restore.py` imports `adapters.wpcli` (cli above adapters, allowed by the `layers` contract). |
| AD-1 | Holds. `adapters/wpcli.py` holds core objects and satisfies the `SearchReplaceCommand` Protocol by composition; no subclassing. Pure pair-ordering and placement rules are in core. Residual: see ED-4. |
| AD-4 | Holds. No `dry_run`/`what_if` in the three new modules (the `--dry-run` hits in `wpcli.py` are WP-CLI's own flag, used for a read-only preview). Dry Run selects `NoopSearchReplace` in `cli/restore.py:1245-1256` via `dry_run_adapters`. |
| ADR-0015 amendment / AD-7 | Holds. No `wp db`, no MySQL client; `wp option list`, `search-replace` and `cli version` only. `wp_cli_environment` gives exactly PATH, HOME, LC_ALL, WP_CLI_CONFIG_PATH (`wpcli.py:185-197`), so the passphrase and `MYSQL_*` never reach `wp`. The password is registered with `SecretRegistry` and argv is logged only via `redact_argv`. `wpcli.py` instantiates no `l3io.wp.database` type; it passes the backup-owned `ExplicitCredentialSpec` (`wpcli.py:629-634`), as the 2026-10-27 amendment requires. Note: ADR-0015 has no 2026-11-06 amendment; the one in force is 2026-10-27, and I judged against that. |
| ADR-0023 amendment (O1 a) | Holds: `replace_file` takes `content: str` (`ports/config.py`, `noop.py`); the no-op twin writes nothing. |
| Port/adapter pattern of new modules | Followed. `ports/search_replace.py` and `ports/site_files.py` are consumed; the extension seam is the E003 Protocol in `cli/restore.py`; the adapter is annotated with core's `RelocationRequest` because adapters may not import `cli/`. |
| Error taxonomy | Consistent. Usage faults are `UsageError` (exit 2); untrusted-input and pre-effect refusals are `RefusedError` (exit 3: `WpCliConfigFoundError`, `InterferingReplacementsError`, `UnsupportedConfigLocationError`, `ConfigLocationConflictError`); post-effect or tool failures are `BackupError` (exit 1); `PreflightFailedError` is NOT_READY (7). docs/restore.md's "exit 3", "exit 2", "exit 1" claims match. |
| docs/restore.md vs behaviour | Matches on config placement, search-replace pairing, env and cwd. One gap: ED-1. |
