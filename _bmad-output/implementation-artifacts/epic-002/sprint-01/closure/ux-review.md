# UX Review — E002 Sprint 01 (CLI-facing output)

- **Scope:** stories E002-S01-001, -003, -004, -005, -006 — help text, error messages, exit codes, log output, README and `docs/logging.md`.
- **Diff:** `3e9f80a..d3e0b2b`
- **Method:** `bmad-ux` Reviewer Gate, headless. The project has no `DESIGN.md` / `EXPERIENCE.md` spine (a CLI with no visual surface), so the rubric walker has nothing to walk and `finalize_reviewers` is empty. One ad-hoc lens ran: **CLI output and operator documentation**, judged against the stories' ACs. The gate's `validation-report.html/.md` were not written, because this review may write only this file.
- **Evidence:** I read the code and ran `wpbackup2` from `uv run` against real inputs: `--help` for each subcommand, no subcommand, a bad `--mode` and `--log-level`, a missing `--wp-dir`, `verify` of the committed fixture, a truncated copy of it, a non-archive file, a missing path and an `s3://` target, `backup` of a missing directory and of a directory with no `wp-config.php`, `restore`, and `python -m wpbackup2`. Every finding below was reproduced or read at the cited line.

## Summary

The core exit-code work holds up. The table is generated from one enum and printed in `--help` and the README. Every failure prints a clear `wpbackup2: error: <cause> [exit N NAME: meaning]` line, and verify's success line names the integrity result. JSON logs carry `run_id` from `run_started` to `run_finished`.

The weak point is the README. It is the first thing an operator reads, and both its install command and its only usage example fail. The CLI also advertises a `restore` that does not exist.

Two problems hurt automation:
- Ordinary operator mistakes (a wrong `--wp-dir`, a missing archive) exit with the catch-all `FAILED` code, which works against story 005's stated goal of letting a scheduler retry transient faults and alert on real ones.
- The `command_failed` record, which holds the operator message, carries no `run_id`, so the per-Run `jq` query that story 004 promises misses the explanation of a failed Run.
